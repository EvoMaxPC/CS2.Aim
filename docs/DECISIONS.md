# DECISIONS.md — Índice de Architecture Decision Records (ADRs)

- **Propósito:** Mantener el registro maestro cronológico de las decisiones arquitectónicas, técnicas y legales de EVO-AIM-CS2 en formato MADR.
- **Fecha:** 2026-11-13
- **Versión:** 1.0.0
- **Estado:** Accepted

---

## Cómo usar este registro

Cada decisión con impacto duradero en arquitectura, dependencias de runtime, multiplataforma, rendimiento o licencias se documenta como un archivo inmutable en [`/docs/adr/`](./adr/). Si una decisión futura reemplaza a una anterior, se crea un nuevo ADR marcando el antiguo como `Superseded by ADR-XXXX`.
